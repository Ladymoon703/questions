# Problem 4: 逻辑回归股票预测

## 问题概述

在这个问题中，我们使用 **逻辑回归模型** 来预测股票价格的涨跌。通过从 **AKShare** 获取 **A股** 数据，我们实现了一个基于历史股票数据的逻辑回归预测模型。该模型的目标是根据股票的历史数据预测下一天的股票价格是否上涨。

## 解决方案

### 步骤1：获取数据

我们使用 `StockDataManager` 类从数据库中获取股票数据。为了模拟获取股票数据的过程，我们设计了一个 `fetch_and_save_data` 方法，该方法能够将获取到的股票数据存入 **SQLite** 数据库。

为了简化，我们使用了模拟数据，实际情况中应使用 **AKShare** 来获取真实的股票数据。通过使用数据库，我们能够高效地存储和检索股票数据。

### 步骤2：特征工程

在特征工程阶段，我们提取了以下几个特征：

- **return**: 股票的每日收益率。
- **ma5**: 5日移动平均。
- **ma10**: 10日移动平均。
- **ma20**: 20日移动平均。
- **momentum**: 股票最近5天的动量。
- **volatility**: 过去5天的波动率。
- **volume_change**: 股票成交量的变化率。

目标变量 **target** 是基于股票的收盘价是否上涨来生成的。如果当天的收盘价高于前一天，则目标变量为 1（上涨），否则为 0（下跌）。

### 步骤3：训练模型

我们使用 **逻辑回归** 模型来对股票的涨跌进行预测。模型的训练使用了以下步骤：

1. **初始化模型参数**，包括学习率、迭代次数、L2正则化项等。
2. 使用 **梯度下降** 算法来最小化损失函数。
3. 在训练数据上迭代更新参数，直到达到设定的迭代次数。

### 步骤4：模型评估

我们在训练集和测试集上对模型进行了评估，使用了以下指标：

- **准确率**（Accuracy）
- **精确率**（Precision）
- **召回率**（Recall）
- **F1分数**（F1 Score）
- **混淆矩阵**（Confusion Matrix）

### 步骤5：特征重要性

通过查看每个特征的权重系数，我们可以评估模型对各个特征的重视程度。
